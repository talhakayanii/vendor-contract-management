# vendor-contract-management
VendoTrack: Smart Contract &amp; Vendor Management System


**VendoTrack** – Smart Contract & Vendor Management System

---

## 📌 Overview

VendoTrack is a web-based vendor contract management system designed to streamline the procurement process and improve efficiency in handling vendor data, contracts, and purchase orders. It supports contract creation, expiration tracking, budget monitoring, and department-based vendor association.

---

## 💡 Features

- 📑 Create, view, and manage vendor contracts
- ⏳ Track contract expiry and upcoming renewals
- 🏢 Link vendors with specific departments
- 💰 Monitor budgets and purchase orders
- 📊 View contract & budget reports
- 🖼️ Simple UI with GIF-based visual feedback

---

## 🧩 Technologies Used

- **Frontend:** HTML, CSS
- **Backend (Database):** MySQL
- **SQL Scripts:** Trigger automation and DDL

---

## 📁 File Structure

| File | Description |
|------|-------------|
| `index.html` | Main dashboard |
| `contract.html` | Manage vendor contracts |
| `department.html` | Department management |
| `purchaseorder.html` | Create/view purchase orders |
| `seebudget.html` | Budget overview |
| `seecontracts.html` | Contract summary |
| `expiringcontracts.html` | Upcoming contract expirations |
| `receiveemessage.html` | Vendor communication |
| `Triggers.sql` | SQL triggers for automation |
| `ddlScript.sql` | Database structure |
| `abc.gif`, `bal.gif`, `ok.gif` | UI GIFs for user interaction |

---

## 🚀 How to Run

1. Clone or download the repository.
2. Import `ddlScript.sql` and `Triggers.sql` into your MySQL database.
3. Open `index.html` in your browser.
4. Optionally, use **XAMPP** or **WAMP** to host the HTML pages with database connectivity.
